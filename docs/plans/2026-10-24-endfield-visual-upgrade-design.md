# Endfield 中央地形、故障弹窗与旋转圆环设计

日期：2026-10-24 ｜ 状态：已批准

## 目标与已对齐决策

在保留现有主菜单结构、文案和入口的前提下完成三项视觉改造：

1. 中央空网格改为 Three.js 真实立体地形，以黑灰底、灰白等高线层级、量化卡通明暗、灰度信标与扫描效果呈现三渲二风格；地形由圆盘容器裁切并铺满整个黑色圆圈。
2. 统一信息弹窗改为终末地黑白线框非对称面板，以 GSAP 和真实卡片内容切片实现边展开边显现的模糊故障和完整退出时间轴。
3. 圆盘外缘白色线条圆环保持静止；其内侧新增一圈黄色长条弧段围绕中心旋转。

已确认：中央地图采用“自动演绎＋鼠标视差”，不支持拖拽或缩放；采用“真实 Three.js 地形＋清晰 DOM/GSAP 弹窗”方案，不引入全屏后处理或画布级文字像素化。

## 参考图视觉语言

- 地图：近黑灰背景，细而清晰的灰白等高线层级，山体有真实高度与遮挡，低饱和信标和纵向光束提供尺度感，界面装饰保持稀疏。
- 面板：黑、炭灰、白与饱和黄色构成主色，硬质切角而非圆润卡片；大号英文与小号中文、编号、刻度、细分割线形成信息层级。
- 动效：分区错位进入，短促水平故障，像素块扫过，随后快速稳定；不使用长时间弹跳、持续 RGB 模糊或影响阅读的 glitch。

## 架构与组件

### 中央等高线

新增文件：

- `src/components/contour-map.tsx`：React 与 Three.js 的边界；挂载容器、传递暂停状态、处理生命周期。
- `src/components/contour-map.css` 对应的样式放在 `src/styles/contour-map.css`：画布、HUD、扫描线和静态标识布局。
- `src/scene/contour-terrain.ts`：Three.js 场景、地形网格、材质、信标、相机、渲染循环和资源释放。
- `src/lib/contour-field.ts`：确定性的高度函数与必要的纯几何计算，不访问 DOM。

在 `Disc` 的现有 `.ef-core__map` 内挂载 `ContourMap`，不改变 `App` 的 SceneLayer 顺序，也不改变 `attach()`、相机弹簧参数、圆盘 reveal/exit 关键帧。现有 `.ef-core__win` 继续负责圆形裁切。

Three.js 使用带真实高度的细分平面、正交或弱透视地图相机和自定义 shader：

- 顶点高度来自确定性多峰地形函数。
- 片元按世界高度计算等高线，使用导数抗锯齿；主/次等高线可有不同强度。
- 等高线按高度从深灰过渡到灰白，底色由少量炭灰阶层构成；只保留黄色定位标记作为界面强调。
- 三个三角信标、地面环与透明纵向光束提供地图节点；扫描带和轻微亮度脉冲负责自动演绎。
- 区域名、坐标和扫描状态采用 DOM 文本，不进入 WebGL 字体渲染。

### 弹窗

重构 `src/components/info-dialog.tsx` 与 `src/styles/info-dialog.css`：

- 面板采用终末地黄色斜切与 coverD 黑白线框的混合构图：左侧黄色楔形和竖排 `ENDFIELD`，顶部为细斜线带，右侧白纸底叠加灰白等高线；标题与中文保持超大层级。
- 保留 `DialogContent`、入口 art、全部现有文案和 meta 数据。
- 故障层改为五道黑、黄、白竖向幕布。幕布按交错节奏从右侧滑入覆盖卡片，再从左侧滑出揭开卡片；标题、说明、数据行和页脚分别错峰显示。

GSAP 时间轴：

- 打开时，五道幕布在约 0.35s 内交错滑入，随后整体轻微放大，幕布再交错滑出；标题、说明、数据行和页脚分层显示。
- 关闭时，内容先分层滑出，幕布交错滑入覆盖卡片，整体缩小后幕布再交错滑出；完成后才调用父组件卸载回调。
- Escape、遮罩与关闭按钮统一调用同一个 `requestClose`，关闭中忽略重复请求。
- `App` 不再绕过退出时间轴直接卸载弹窗；Escape 只由弹窗关闭流程处理，避免连带关闭菜单。

### 旋转圆环

在 `DialRings` 的新增黄色弧段内增加 `.ef-dial__orbit` 嵌套组：

- 白色外缘线条与琥珀色虚线环保持静止。
- 白色弧段内侧新增两段短黄色半透明长条弧，它们作为一组缓慢围绕中心旋转。
- 原 `.ef-dial__ink`、`.ef-dial__seg` 的入场/退场动画与所有 attach 高度保持不变。
- 完整圆环和实心环带不做不可见的无效旋转。
- 菜单暂停和 `prefers-reduced-motion: reduce` 时停止持续旋转。

## 数据流与生命周期

- React 只管理现有菜单相位、弹窗内容和低频暂停状态；不保存逐帧地形、相机或 GSAP 数据。
- `App` 将 `paused` 传入中央地图，并在舞台元素上暴露低频暂停属性供圆环 CSS 使用。
- Three.js 指令式控制器持有 renderer、scene、camera、几何、材质、rAF、指针目标和时间；暂停恢复时重置计时，避免时间跳跃。
- `ResizeObserver` 更新画布尺寸，像素比设置上限；页面隐藏、弹窗打开和菜单退出时停止内部演绎。
- reduced motion 下渲染静态地形并直接显示弹窗最终状态。
- 卸载时取消 rAF、断开 observer、移除事件监听、释放 geometry/material/renderer，并 `kill`/`revert` GSAP 动画。
- WebGL 初始化失败属于浏览器能力边界：保留现有深色网格和菜单功能，不抛出导致整页崩溃的错误。

## 测试设计

遵守“手搓测试、禁止新增测试框架”的项目约束。

### 纯函数

为 `contour-field` 增加 Node `assert` 测试：确定性、有限值、预期地形范围及关键采样点。测试纳入 `check:libs`，不改变 demo 几何函数的逐字节比对。

### 原逐帧验收

本次有意偏离 demo 的中央圆盘区域，原样比较必然失败。`frame-check.mjs` 采用明确、固定的中央区域遮罩，仅对该区域豁免 demo 像素一致性；其余菜单区域继续按原容差逐帧比对，demo 目录保持只读。

### 新交互与视觉验收

新增手搓 CDP 应用侧检查并纳入 `check:frames`：

- WebGL 画布已渲染，中央内部截图存在足够数量的青绿/荧黄地形像素，而非空白或 fallback。
- 自动演绎期间中央内部画面发生变化。
- 圆环在不同动画时间产生不同变换，reduced motion 下静止。
- 弹窗能从真实按钮打开，进入稳定态后通过按钮、遮罩和 Escape 完整退出；退出后主菜单仍保持打开。
- reduced motion 下弹窗直显/直退；检查浏览器异常与 console error。

最后在浏览器手动检查：正常入场、地图自动演绎和鼠标视差、圆环旋转、多个不同内容弹窗、连续开关、Escape、菜单重开、小视口和 reduced motion。
